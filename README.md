# Sito-web
# Portfolio Professionale - Serena Farina

Sito web portfolio personale di Serena Farina, progettato per presentare i servizi e i progetti realizzati nei campi dell'Interior Design e della Fotografia. Il sito è strutturato per offrire un'esperienza visiva pulita, moderna e responsive.

Sito online: https://serenafarina-prog.github.io/Sito-web/index.html


Tecnologie Utilizzate

Il progetto è sviluppato con tecnologie web standard e librerie mirate per garantire leggerezza e performance:
HTML5 & CSS3 - Struttura e stili personalizzati
Bootstrap 5 - Per la griglia e componenti responsive
JavaScript - Per la logica interattiva, inclusa la gestione modulare del menu mobile
EmailJS - Per la gestione diretta del form di contatto
Google Fonts - Tipografia con Karla e Montserrat



Struttura delle Cartelle

La struttura del progetto è organizzata in modo modulare:

Sito-web/
├── assets/
│   ├── css/                # Fogli di stile personalizzati
│   ├── images/             # Immagini suddivise per categorie (Interior, Photography, Cover)
│   ├── js/                 # Script JavaScript (menu.js)
│   ├── sass/               # File sorgente Sass/SCSS
│   └── video/              # Video dimostrativi
├── contacts/               # Pagina Contatti
├── cv/                     # Pagina Curriculum
├── portfolio/              # Sezioni di Interior Design e Fotografia
├── index.html              # Homepage del sito
└── README.md               # Documentazione del progetto



Come visualizzarlo in locale

Se desideri visualizzare e testare il sito direttamente sul tuo computer prima della pubblicazione:
1. Apri la cartella del progetto utilizzando il tuo editor di codice (ad esempio Visual Studio Code).
2. Per un corretto funzionamento dei percorsi e degli script, ti basta aprire la cartella in VS Code e avviare il file principale `index.html` utilizzando un server locale (come l'estensione Live Server).
